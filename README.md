# 🛡️ Web Audit Keamanan Informasi

Aplikasi berbasis web sederhana yang dirancang untuk mendukung proses evaluasi, pencatatan, dan audit risiko keamanan sistem informasi secara efisien. Aplikasi ini terintegrasi langsung dengan **Supabase** sebagai *backend/database* secara real-time.

---

## 📌 Fitur Utama
* **Dashboard Audit Keamanan:** Antarmuka intuitif untuk menginput dan meninjau data audit risiko TI.
* **Integrasi Database Real-time:** Penyimpanan dan pengelolaan data audit menggunakan Supabase.
* **Keamanan Data:** Menerapkan prinsip *Row Level Security* (RLS) untuk menjaga integritas data audit.

---

## 🛠️ Teknologi yang Digunakan
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Backend / Database:** Supabase (PostgreSQL & Database Client SDK)
* **Version Control:** Git & GitHub
